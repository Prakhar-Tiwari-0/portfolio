# Prakhar Tiwari — portfolio

A minimal, off-white portfolio. No terminal UI, background images, animations, or theme dependencies. Photos remain on a separate credits page.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Deploy on Vercel

Push this folder to GitHub, import the repository at https://vercel.com/new and use the default Next.js settings. No environment variables required.

## Content

Edit `app/page.tsx` for homepage text, links, projects, experience, and publications. Edit `app/photos/page.tsx` for photos and captions. Images are stored in `public/photos`. Styles are in `app/globals.css`.
